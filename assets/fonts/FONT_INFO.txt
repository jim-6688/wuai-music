# GlassMusic 字体配置
# 使用 Google Fonts 的 Inter 字体 - 现代化无衬线字体
# 
# Inter 字体特点：
# - 专为屏幕设计
# - 高可读性
# - 多语言支持
# - SIL 开源许可证 (OFL)
#
# 字体权重：
# - Regular (400) - 正文
# - Medium (500) - 强调
# - SemiBold (600) - 标题
# - Bold (700) - 重点
#
# 使用方式：
# Text(
#   'Hello GlassMusic',
#   style: TextStyle(
#     fontFamily: 'Inter',
#     fontWeight: FontWeight.w600,
#     fontSize: 24,
#   ),
# )
