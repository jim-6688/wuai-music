隐私政策

吾爱音乐 WuAiMusic · 生效日期：2026 年 11 月 26 日

一、适用范围

本政策适用于吾爱音乐 WuAiMusic 的手机、桌面、电视、车机端应用，以及数播 Web 管理端（以下合称“本产品”）。本产品是本地音乐播放器：曲库扫描、标签读取、歌词与封面解析、播放解码默认在本机完成。

本产品不内置在线歌词源，不抓取第三方曲库的歌词正文，不解码任何平台私有歌词格式。需要联网时，均由用户主动配置或主动触发。

二、我们处理哪些信息

1. 仅在本地处理的信息

  • 音频文件、文件名、目录结构与曲库列表；
  • 音频标签、内嵌封面、同目录封面图片；
  • 本地 LRC / 增强 LRC 歌词、逐字时间轴、用户手动校准记录；
  • 播放历史、收藏、评分、播放队列、本地设置与缓存。

这些信息默认保存在你的设备或你主动配置的存储位置。本产品不会读取通讯录、短信、通话记录、相册全量内容，也不会获取 IMEI、MAC 地址、设备序列号等硬件唯一标识。

2. 用户主动配置后才会发送的信息

  • 自定义歌词源：只有当你自行填写并启用某个歌词源地址时，本产品才会把检索所需的歌名、歌手、专辑、时长等最小元数据发送到该地址；不会上传音频文件。该地址由你自行选择，其数据处理行为受该服务方规则约束。
  • 原创填词服务：若你在数播端配置模型供应商、接口地址与 API Key，本产品会把曲目信息作为创作主题发送给该模型服务，用于生成全新歌词与 LRC 时间轴；不会上传音频文件，也不会要求模型回忆已有歌曲的歌词。
  • 更新检查：检查新版本时会访问官网发布的版本清单，用于比较版本号与获取下载地址。
  • 授权与配对：使用授权校验、手机与电视/车机配对、NAS/WebDAV 连接等功能时，会把完成该功能所必需的连接信息发送到你配置或界面明示的服务端。

上述通信都不是默认内置的内容抓取；除更新检查外，均由用户主动配置或主动触发。

3. 日志与诊断

当前版本已彻底停用运行日志与崩溃信息的自动上报，应用不会自动向外部发送错误日志或堆栈。日志保留在本机，可在应用的“日志与诊断”中查看、导出或清除。

三、权限说明

  • 存储 / 文件访问：读取你指定的音乐目录，解析歌词与封面，写入必要的本地缓存和侧车文件。
  • 网络：仅在检查更新、访问你配置的歌词源 / 填词服务 / NAS 服务等场景使用。
  • 通知与后台播放：显示播放控制与媒体信息。
  • 蓝牙 / 局域网发现：仅在配对与控制外部播放设备、发现局域网服务时使用。

你可以在系统设置中撤回相关权限；撤回后对应功能可能不可用，但不影响本机离线播放。

四、Cookie、广告与第三方 SDK

本产品没有账号体系，不投放广告，不使用第三方行为分析 SDK，不跨应用追踪你的听歌行为。官网仅使用必要的静态资源；本政策页面不设置用于广告追踪的 Cookie。

五、数据保留与删除

  • 本地曲库、缓存、歌词校准记录保存在你的设备上，可在应用设置中清理缓存，或自行删除对应目录。
  • 你配置的用户名、地址、令牌与 API Key 保存在本机或你指定的同步位置；清除应用数据会一并删除。
  • 发送到你配置的歌词源、填词服务或授权服务的数据，由对应服务方按其规则保存与处理；本产品不保留副本。

六、儿童与敏感信息

本产品不是面向 14 岁以下儿童的服务，也不会主动收集儿童个人信息。请不要在歌词、文件名、自定义源地址或反馈内容中填写身份证号、银行卡号等敏感信息。

七、政策更新与联系

本政策随产品能力变化可能更新，更新日期以本页面顶部为准。重大变更会在官网或应用内提示。
