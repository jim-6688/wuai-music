01 / 为什么存在

不另起炉灶，是把现有系统测量化

实验室和“从零搞研发”最大的区别，是已经有研究者拿不到的实验对象：一条真实可测的播放链路，和一个 40GB 的真实中文曲库。别人要搭这套台子得先买设备、攒数据；我们现成。

“咱们做的功能准确吗？都是真实专业的吗？还是纸老虎？” 工作室的起点，是一次不哄不贬的功能真实性审计。
02 / 主攻痛点与论证

把功能拆成三级，用证据说话

不吹牛，也不一棍子打死。下面每一条都对着代码和实测，而不是功能列表。

真金 · 有硬证据

对内的基建

真实实现，敢亮细节。

  • 曲库落盘：1540 文件零缺失、大小全对
  • 硬件 ID：整机指纹，换配件跟着变
  • 感知音量曲线、密码恢复出厂
  • DSD / ReplayGain 标注诚实，非位流不冒充
半真 · 证据链有洞

解析真，来源不稳

实现是真的，但依赖非官方接口。

  • 逐字歌词：真移植，但多源随时失效
  • 封面刮削：同上，来源不稳定
  • CamillaDSP：真实现，但明确非 bit-perfect
纸老虎 · 名不副实

对外的招牌

喊得最响的，恰恰最经不起追问。

  • bit-perfect 假绿灯：读不到硬件证据就默认判直通
  • “智能”心情分类：实为关键词打分，曲库零真标签
  • 六源/四源数字好看，但来源随时被收走
  • 硬件 ID “授权激活”：ID 真，激活未落地
核心判断：对外的招牌基本是纸老虎，对内的基建基本是真金——错位才是痛心的根源。

去纸老虎化第一步很具体：假绿灯改“待验证”而不是默认绿、hw_params 只读当前启用的那一路、把信号链实测数据沉淀成可导出的证据。让“透明”从口号变成能亮出来的东西。

✓ 已落地（2026-11-20）：上面三步已在 T1S 参考机上线——无硬件证据显示“待验证”、播放时只读当前输出 hw_params（实测 S16_LE @ 44.1 kHz）、并提供 /api/signal-chain 证据快照与 CSV 导出，任何人可复算。信号链透明白皮书有了第一份真实数据源。

03 / 三大主攻方向

文件 → 比特 → 听觉，一条链

三个方向不是三个项目，是同一条信号链上的三段。都有现成基础，不是从零起。

DIRECTION 01

AI + 智能声场

最远：需测量麦与听感验证

用测量麦克风采集房间响应，自动生成 PEQ 灌进 CamillaDSP，做可复现的自动房间校正。不自研大算法，切入点是“测量 → 生成 PEQ → 灌 DSP”工程闭环。

切入点：测量 → PEQ → CamillaDSP
DIRECTION 02

bit-perfect 与信号链透明

最先：成本最低、最能立信誉

把 analyze_playback 从“声明”变“证据”：每步采样落盘——源规格、解码、重采样、hw_params 实测、时间戳；无证据标“待验证”，导出 JSON / CSV 任何人可复算。DDC 到货前后各测一遍，就是现成对比实验。

第一份产出：《信号链透明白皮书》
DIRECTION 03

本地曲库智能化整理

居中：产品价值最快

文本优先、指纹兜底：时长交叉验证淘汰误匹配，激进清洗脏文件名，先锁专辑再配曲目；每确认对一首，就沉淀一条“指纹/时长/文件名 → 元数据”的本地映射。识别对一首，数据飞轮长一格。

自有资产：中文曲库映射数据集

07 / 深度研究

把讨论沉淀成方法，把方法写成文章

下面每一条都是一轮追问后的判断，不是功能介绍。成型的会写成可复现的研究文章，持续追加。

架构判断

数播像「重造」而非「升级」，根因是缺平台无关的核心层

数播不跑 Flutter，歌词/封面/元数据/心情只能复刻，真正共享的只有 HTTP API、MPD 协议与 MOOD 标签三处契约。一半重造是必然且正确（J1900 跑不动 Flutter、会破坏 bit-perfect），缺的另一半是当初埋在 lib/features 里、没沉淀成独立层的平台无关核心逻辑。

道与术

bit-perfect 修「说的能不能对」，核心价值建「说的能不能信」

DDC 到货一测便知，是术；可验证 + 懂中文曲库才是值得长期投入的道。二者共享同一份数据底座——信号链实测数据与曲库语义数据，走同一个「采集 → 沉淀 → 导出」结构。低频高杠杆，不搞大干快上。

方法诊断

AcoustID 匹配「同一段录音」，而整理要问「哪一首歌」

中文曲库难，不是没源，是文本脏加缺少交叉验证——目标错配才是根因。路线是文本优先、指纹兜底：时长交叉验证淘汰误匹配、激进清洗文件名、先锁专辑再配曲目。已写成研究文章。

08 / 诚实边界

把丑话说前面，免得又成纸老虎

不碰这三样

  • 流媒体授权：门槛在商务资质，谈不动，不在实验室射程内。
  • 自研大算法：声场那块用成熟测量 + PEQ 工程闭环，不做算法军备竞赛。
  • 把“可插拔”当答案：拔得快不等于消除授权风险，只能止损。
诚实代价：数据飞轮冷启动慢、头几个月覆盖率低；语义数据靠“用户确认”喂养，所以产品机制必须让人愿意确认——不能悄悄改库。
